# RF-Quiz — результат доработки 7 ноября 2026

Работа выполнена в существующем проекте. Сохранены Node.js, стандартный HTTP-сервер, SSE, статические HTML/CSS/JavaScript, локальные QR-коды и Web Audio. Runtime-зависимости не добавлялись. Вопросы хранятся в `questions.json`, игра и игроки — в памяти процесса, иллюстрации вопросов — в `images/`. Маршруты `/host`, `/play`, `/editor` сохранены; `/present` использует тот же игровой рендерер с отдельным режимом проектора. `render.yaml` и переменные окружения не изменены.

Резервная копия исходных изменяемых файлов находится в `backups/2026-11-07-youth-quiz/`. Она включает прежние вопросы, сервер, клиент и фотографии, удалённые из публичной папки. Резервная копия исключена из Git и недоступна через HTTP. Исходные пользовательские PDF/DOCX в корне проекта не изменялись.

Реализованы:

- Все 25 вопросов и 100 вариантов из ТЗ без изменения текста, ключей, порядка и тематического деления 15/10. Время по умолчанию 30 секунд, редактор позволяет менять его от 5 до 300 секунд.
- Эмодзи вместо фотографий на регистрации, в лобби, рейтингах и пьедестале. Удалены сопоставление имени фотографии, передача фотографий по API и публичные файлы участников.
- Три представления: управление, проектор, участник. QR-код, ссылка, шестизначный код комнаты, список и число подключённых игроков.
- Цветные карточки А/Б/В/Г, перенос длинного текста, прогресс квиза, круговой и линейный таймеры, светлая и тёмная темы.
- Серверные стадии: лобби → вопрос ↔ пауза → закрытое голосование с распределением → ручное раскрытие → необязательный рейтинг → следующий вопрос/финал.
- Прежняя формула правильного ответа 500–1000 баллов. Пауза исключена из времени ответа. Неверные и пропуски дают 0. Убрано дополнительное окно приёма после дедлайна.
- Подтверждение выбранного ответа, блокировка кнопок, серверный запрет повторов и проверка номера раунда для защиты от запоздавшего запроса предыдущего вопроса.
- Топ-5, изменение места, анимация перестановки и счётчиков, выделение нового лидера, возможность скрыть промежуточный рейтинг с телефонов и проектора. Финал: три победителя и полная таблица.
- Звуки старта, последних секунд, завершения, раскрытия, рейтинга и финала; общий переключатель звука в каждом представлении. Конфетти без библиотек, учёт уменьшения движения.
- Командный режим с четырьмя командами, выбором до старта и суммированием личных очков. После старта команду менять нельзя. В финале доступны командный и личный рейтинги.
- Редактор со списком слева, предпросмотром, названием квиза, категорией, текстом, четырьмя вариантами, правильным ответом, временем, пояснением, иллюстрациями вопросов, порядком, сохранением, импортом/экспортом JSON.
- CSV с полным личным рейтингом и ответами каждого раунда, в том числе пропусками. Записи сохраняют имя на момент раунда.
- Восстановление игрока в той же вкладке по случайному секрету, автоматическое переподключение SSE. Ведущий восстанавливает состояние после обновления страницы. Секреты игроков не передаются другим клиентам. SSE ведущего использует HttpOnly-cookie, административный пароль не добавляется в URL потока или QR-код.

Дизайн развивает прежнее оформление RF-Quiz. Ориентир по игровым UX-паттернам — [AhaSlides](https://ahaslides.com/) и его [Pick Answer](https://games.ahaslides.com/pick-answer). Фирменные материалы и код референса не копировались.

Ограничения: настоящие смартфоны, Safari/iOS, физический проектор и Wi-Fi мероприятия не проверялись. Действующий Render позднее проверен с 50 одновременными сессиями — см. [LOAD_TEST_RENDER.md](LOAD_TEST_RENDER.md). Браузерная проверка мобильного размера выполнена в Chrome. Звуки реализованы, их субъективное качество через реальные колонки не прослушивалось. Запуск именно на Node.js 18 отдельно не проверялся; приложение сохраняет прежнее требование Node.js ≥18, текущий Playwright для разработки требует Node.js ≥20. Тест с 30 соединениями выполнен локально и не является измерением реальной сети или хостинга.

Игра остаётся в памяти одного процесса: перезапуск сервера сбрасывает её; горизонтальное масштабирование без общего хранилища не предусмотрено. Вопросы на хостинге без постоянного диска нужно сохранять экспортом JSON. Секрет игрока хранится в текущей вкладке; восстановление только по имени намеренно запрещено. Код комнаты — удобный идентификатор одной комнаты, его ручной ввод необязателен. В командном режиме сумма очков зависит от размера команды, поэтому составы следует выровнять до старта.

Точная команда запуска: `npm start`. Адреса: `http://localhost:3000/host`, `http://localhost:3000/present`, `http://localhost:3000/play`, `http://localhost:3000/editor`. Все принадлежащие тестам серверы остановлены; результат последующей публикации и проверки Render описан в [LOAD_TEST_RENDER.md](LOAD_TEST_RENDER.md).
