# RF-Quiz

Квиз «Посвящение Богу своей воли. Разум и чувства»: 25 вопросов, 100 вариантов ответа. Первые 15 вопросов — посвящение воли, последние 10 — разум и чувства. Формулировки, ключи и порядок сохранены из ТЗ.

Запуск из папки проекта:

```sh
npm start
```

Нужен Node.js 18 или новее. Для самого приложения установка пакетов не требуется: сервер использует только стандартные модули Node.js.

| Страница | Адрес на компьютере ведущего |
| --- | --- |
| Панель ведущего | http://localhost:3000/host |
| Проектор | http://localhost:3000/present |
| Участник | http://localhost:3000/play |
| Редактор | http://localhost:3000/editor |

Для телефона используйте адрес локальной сети, напечатанный сервером и показанный в QR-коде. `localhost` на телефоне указывает на сам телефон. При работе в локальной сети компьютер и телефоны должны иметь доступ друг к другу. В Render применяется прежний `render.yaml`; `PORT`, `HOST_PASSWORD`, `PUBLIC_URL` и `RENDER_EXTERNAL_URL` поддерживаются, конфигурация деплоя не изменена.

Без `HOST_PASSWORD` ведущий на этом компьютере входит автоматически; для другого устройства сервер печатает случайный пароль текущего запуска. Если `HOST_PASSWORD` уже задан, используйте его. Пароль вводится на `/host` и `/present`, в QR-код он не попадает.

1. Откройте `/host` и `/present` в разных вкладках. На проекторе доступен полноэкранный режим ⛶.
2. Участники сканируют QR-код или открывают `/play`, вводят имя и выбирают эмодзи. Код игры можно ввести вручную; в QR-ссылке он уже указан. В приложении одна игровая комната.
3. При желании переключите «Личная игра» на «Командная игра» до старта. Есть четыре команды: Свет, Надежда, Вера, Любовь. Игроки могут выбрать команду при регистрации или сменить её в лобби. Без выбора сервер распределяет игроков по командам с меньшим количеством участников. Командные очки — сумма личных; для равных условий выбирайте команды одинакового размера. После старта смена команды заблокирована.
4. Нажмите «Начать игру». На вопрос по умолчанию даётся 30 секунд. Пауза останавливает серверный таймер и приём ответов; время паузы не влияет на баллы.
5. По истечении времени или кнопке «Завершить приём» ответы блокируются. Показывается распределение вариантов, правильный ответ остаётся скрытым. Ведущий нажимает «Раскрыть ответ», затем может открыть рейтинг либо перейти дальше.
6. «Скрыть рейтинг» убирает промежуточную таблицу с телефонов и проектора. Ведущий продолжает её видеть. В финале рейтинг открыт всем: пьедестал и полная таблица.
7. После последнего вопроса откроется финал. CSV содержит личный рейтинг и ответы по раундам, включая пропуски. «Новая игра» сбрасывает очки и историю; перед сбросом скачайте CSV. «Сбросить игру» и «Завершить игру» требуют второго нажатия.

Правильный ответ приносит `round(1000 - 500 * elapsed / totalTime)` баллов, неверный или пропущенный — 0. Используется серверное время, паузы исключаются. При равенстве очков учитывается суммарное время ответов. Один игрок может ответить на каждый вопрос один раз.

В редакторе слева находится список вопросов, справа — предпросмотр и поля выбранного вопроса. Нажмите на букву ответа, чтобы выбрать правильный. Можно менять порядок, текст, тему, пояснение, время и иллюстрацию вопроса. Фотографий участников нет. Сохранение разрешено до старта и после финала. Импорт JSON принимает `answers` или `options`, ровно четыре варианта и `correct` от 0 до 3; импорт сначала загружается в редактор, затем применяется кнопкой «Сохранить». Экспортируйте JSON, чтобы сохранить изменения вне сервера.

Звуки синтезируются браузером и по умолчанию отключены. Включайте их на одном из экранов, чтобы не получить двойное воспроизведение. Браузеру нужен первый клик для активации звука. Тема переключается кнопкой ◐. Для системного режима уменьшения движения анимации отключаются.

Идентификатор и случайный секрет игрока хранятся в `sessionStorage`. Перезагрузка вкладки и кратковременный обрыв соединения сохраняют игрока, ответ и очки. Для восстановления нужна та же вкладка; имени или публичного ID недостаточно. После закрытия вкладки её секрет может быть утрачен. Ведущий может удалить такой профиль в лобби.

Состояние игры хранится в памяти одного процесса, вопросы — в `questions.json`, иллюстрации вопросов — в `images/`. Перезапуск процесса сбрасывает игру и сессии. Изменения JSON/иллюстраций на хостинге без постоянного диска могут быть потеряны при перезапуске или новом деплое. Держите один экземпляр сервера на комнату. Перед мероприятием проверьте доступность хостинга и подключение настоящих телефонов.

Проверки:

```sh
npm ci
npm run check
npm test
npm run test:e2e
```

Playwright — зависимость только для разработки; для текущей версии нужен Node.js 20 или новее. На macOS тест использует установленный Google Chrome. На другой системе установите Chromium командой `npx playwright install chromium`; можно указать путь через `PLAYWRIGHT_CHROME_PATH`. Браузерный тест использует порт 3117 и изолированную временную копию сервера: рабочий JSON не изменяется. `npm run check` сравнивает поставляемый контент с ТЗ; после осознанной смены содержания квиза это сравнение будет сообщать о различиях.

Подробный результат работ и ссылки на скриншоты: [IMPLEMENTATION.md](IMPLEMENTATION.md).

Проверка реального сервиса с 50 имитированными участниками:

```sh
npm run test:load -- https://quiz-841v.onrender.com --password-stdin
```

Введите действующий пароль ведущего в терминале после приглашения; он не отображается и не сохраняется в отчёте. Тест запускается только в пустом лобби, проходит 25 вопросов, проверяет серверный таймаут, одновременно отправляет ответы 50 игроков, восстанавливает пять соединений и удаляет свои профили. Используется HTTP/2: 50 независимых игровых потоков и параллельные HTTP-запросы. Отчёт с задержками сохраняется в `artifacts/load/`. Это тест 50 игровых сессий с одного компьютера, а не 50 физических телефонов из разных сетей.

Результат выполненной проверки: [LOAD_TEST_RENDER.md](LOAD_TEST_RENDER.md).
